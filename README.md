# Academic Materials Management System

## 📚 About the Project

The **Academic Materials Management System** is an information system developed as a diploma project for **Fan S. Noli University**.

The main purpose of the system is to provide a centralized digital platform for managing, organizing, searching and accessing academic materials. It is designed to facilitate the interaction between administrators, lecturers, students and external users.

## 🎯 Main Objectives

* Centralize academic materials in a structured digital platform.
* Allow lecturers to upload and manage academic materials.
* Enable students to search, access and download available materials.
* Provide administrators with tools for managing users and system content.
* Improve the distribution and accessibility of academic information.
* Provide a simple and user-friendly interface.

## 👥 User Roles

The system includes different types of users:

* **Administrator** – manages users, books, materials and system activities.
* **Lecturer** – uploads academic materials and publishes announcements.
* **Student** – searches, accesses and downloads academic materials.
* **External User** – can register and access publicly available resources.

## ⚙️ Main Features

* Academic material management
* Book and lecture management
* Search functionality
* User authentication and sessions
* Role-based access
* Notifications and announcements
* Comments and testimonials
* Academic material downloads
* Administrative dashboard
* PayPal integration
